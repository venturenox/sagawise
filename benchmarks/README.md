# Benchmark data

Raw output of `make bench` and `make bench-profile`: one directory per run under `runs/`, never overwritten; comparison reports from `make bench-compare` under `comparisons/`; `plot.py` redraws the charts into `docs/assets/benchmarks/`.

The method, what each number means and how performance moved over time: [docs/benchmarks.md](../docs/benchmarks.md).
